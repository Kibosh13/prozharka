# Backend подписки «Прожарка»

Каркас рассчитан на PHP 8.2+, SQLite, Telegram Bot API и вебхуки Prodamus. Боевые ключи в репозитории не хранятся.

## Сценарий покупки

1. На сайте покупатель вводит ФИО, телефон, email и `@username` Telegram, а также отдельно принимает согласие на обработку данных и публичную оферту.
2. `POST /api/checkout` создаёт заказ и возвращает подписанную ссылку Prodamus.
3. Только валидный webhook Prodamus переводит заказ в статус `paid`.
4. Сразу после подтверждения платежа обработчик запускает выдачу отдельной Telegram-ссылки с лимитом в одного участника. Ссылка действует до конца оплаченного периода.
5. Страница `payment.html` опрашивает статус заказа и показывает ссылку после оплаты. Если неиспользованная ссылка устарела, открытие страницы автоматически создаёт новую без повторной оплаты.
6. Когда участник входит по этой ссылке, Telegram присылает `chat_member`; бот связывает заказ с неизменяемым числовым Telegram ID.
7. Повторная оплата с теми же телефоном и email продлевает `expires_at` ещё на 30 дней. Участник остаётся в канале без новых приглашений.
8. После окончания срока и grace-периода worker удаляет только участников с `managed_by_bot=1` и `protected_existing=0`.

Для каждого созданного заказа в `consent_records` фиксируются дата принятия, версии документов, выбор cookies, IP-адрес и User-Agent. Версии документов задаются в `.env`, чтобы доказательство согласия оставалось связано с опубликованной редакцией.

Участники, уже находившиеся в канале до запуска системы, не входят по ссылкам бота, не получают `managed_by_bot=1` и никогда не попадают в очередь удаления.

## Безопасность запуска

- Скопировать `.env.example` в `.env` и задать права `600`.
- Никогда не хранить токен Telegram, ключ Prodamus и `.env` в Git.
- Оставить `DRY_RUN=1` и `ACCESS_REMOVAL_ENABLED=0` до полной тестовой оплаты.
- Боту нужны права администратора на создание пригласительных ссылок и блокировку участников.
- В Prodamus указать `https://prozharka-tg.com/api/webhooks/prodamus` для обычных и рекуррентных уведомлений.
- Telegram webhook: `https://prozharka-tg.com/api/webhooks/telegram` с секретным заголовком.
- База SQLite должна находиться вне `public_html` или быть недоступна из веба.
- Cron запускает `php backend/bin/worker.php` каждые 5 минут.

## Локальная проверка

```sh
php backend/tests/run.php
```

Для инициализации пустой базы после заполнения `.env`:

```sh
php backend/bin/init-db.php
```

## Настройка Prodamus

- URL платёжной формы;
- секретный ключ;
- webhook `https://prozharka-tg.com/api/webhooks/prodamus` для события «Заказ оплачен».

По умолчанию используется ручное продление: каждый успешный платёж на 4 990 ₽ добавляет 30 дней доступа. Каталог продуктов и сохранённая платёжная ссылка в кабинете не требуются — сервер формирует персональную подписанную ссылку через параметры `products`.

Если позже будет подключён клубный функционал Prodamus с автосписаниями, достаточно указать `PRODAMUS_SUBSCRIPTION_ID`: код автоматически начнёт формировать рекуррентные ссылки вместо разовых.
