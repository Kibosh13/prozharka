# Backend подписки «Прожарка»

Каркас рассчитан на PHP 8.2+, SQLite, Telegram Bot API и вебхуки Prodamus. Боевые ключи в репозитории не хранятся.

## Сценарий покупки

1. На сайте покупатель вводит ФИО, телефон, email и `@username` Telegram.
2. `POST /api/checkout` создаёт заказ и возвращает подписанную ссылку Prodamus.
3. Только валидный webhook Prodamus переводит заказ в статус `paid`.
4. Worker создаёт отдельную ссылку Telegram с лимитом в одного участника и сроком 24 часа.
5. Страница `payment.html` опрашивает статус заказа и показывает ссылку после оплаты.
6. Когда участник входит по этой ссылке, Telegram присылает `chat_member`; бот связывает заказ с неизменяемым числовым Telegram ID.
7. Продление только обновляет `expires_at`. Участник остаётся в канале без новых приглашений.
8. После окончания срока и grace-периода worker удаляет только участников с `managed_by_bot=1` и `protected_existing=0`.

Участники, уже находившиеся в канале до запуска системы, не входят по ссылкам бота, не получают `managed_by_bot=1` и никогда не попадают в очередь удаления.

## Безопасность запуска

- Скопировать `.env.example` в `.env` и задать права `600`.
- Создать новый токен Telegram перед запуском; опубликованный в переписке токен использовать нельзя.
- Оставить `DRY_RUN=1` и `ACCESS_REMOVAL_ENABLED=0` до полной тестовой оплаты.
- Боту нужны права администратора на создание пригласительных ссылок и блокировку участников.
- В Prodamus указать `https://prozharka-tg.com/api/webhooks/prodamus` для обычных и рекуррентных уведомлений.
- Telegram webhook: `https://prozharka-tg.com/api/webhooks/telegram` с секретным заголовком.
- База SQLite должна находиться вне `public_html` или быть недоступна из веба.
- Cron запускает `php backend/bin/worker.php` каждые 5 минут.

## Локальная проверка

```sh
php backend/tests/run.php
```

Для инициализации пустой базы после заполнения `.env`:

```sh
php backend/bin/init-db.php
```

## Что потребуется из Prodamus

- URL платёжной формы;
- секретный ключ;
- ID рекуррентной подписки;
- подтверждение параметров и тестовый webhook из личного кабинета.
