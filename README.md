# Прожарка

Одностраничный сайт закрытого Telegram-проекта Татьяны Гальцевой: тренировки, питание и растяжка с понятным планом на месяц.

## Структура

- `dist/index.html` — страница лендинга;
- `dist/styles.css` — адаптивная стилизация и анимации;
- `dist/script.js` — навигация, раскрытие контента и эффекты прокрутки;
- `dist/assets/` — оптимизированные фотографии проекта;
- `dist/privacy/`, `dist/consent/`, `dist/offer/` — веб-версии юридических документов;
- `dist/documents/` — исходные юридические документы DOCX;
- `scripts/build_legal_pages.py` — повторная сборка веб-версий документов из DOCX;
- `backend/` — безопасный каркас подписок, webhooks Prodamus и управления доступом в Telegram.
- `backend/src/SiteContent.php` — хранение и серверный вывод редактируемого контента;
- `deploy/admin/` — авторизованный редактор сайта на Beget;
- `deploy/beget-site-index.php` и `deploy/beget-site.htaccess` — PHP-страницы боевого сайта.

## Редактор сайта

На боевом домене редактор доступен по адресу `https://prozharka-tg.com/admin/`.
В нём меняются тексты всех страниц, фотографии и кадрирование, контакты, стоимость участия,
сообщения cookies/оплаты, заголовки и описания для поиска, обложка для мессенджеров и индексация.
Цена новых заказов синхронизирована с ценой на странице. Уже созданные заказы сохраняют прежнюю сумму.

«Предпросмотр» показывает несохранённые правки на компьютере и телефоне. «Сохранить на сайте»
публикует все правки вместе. В истории остаются 20 предыдущих версий. Пароль меняется в разделе «Пароль».
Редактор изменяет веб-версии юридических документов; исходные DOCX остаются исходными файлами.

Контент, история и хеш пароля находятся в `_backend/var/`, загруженные фотографии — в `assets/uploads/`.
Они не включаются в Git и должны сохраняться при любом обновлении исходников. Шаблоны боевого сайта
лежат в `_backend/templates/`: публичные HTML-файлы заменены PHP-маршрутами, чтобы nginx не отдавал
устаревший статический файл в обход редактора. В GitHub Pages остаётся статическая демоверсия без админки.

Для первого создания администратора на сервере запустите `php8.3 _backend/bin/setup-admin.php tatyana`
и передайте пароль через stdin. Команда хранит только хеш и не перезаписывает существующую учётную запись.
Нельзя публиковать `var/` или переносить туда конфигурацию из другой среды.

Локальный редактор: `php -S 127.0.0.1:4173 -t dist scripts/preview-cms.php`.
Проверки: `php backend/tests/cms.php`, `php backend/tests/run.php`.
HTTP-проверка загрузки и авторизации: `node scripts/check-cms-http.mjs http://127.0.0.1:4173`;
пароль передаётся через stdin. Эта проверка не меняет опубликованный контент.

## Локальный просмотр

Откройте `dist/index.html` в браузере или запустите простой статический сервер:

```sh
python3 -m http.server 4173 --directory dist
```

## Публикация

- исходники находятся в ветке `main`;
- статическая демонстрация публикуется из ветки `gh-pages`;
- демонстрационная версия закрыта от поисковой индексации через meta robots и `robots.txt`.

Боевые ключи оплаты и Telegram в репозитории не хранятся. Порядок подключения описан в `backend/README.md`.
