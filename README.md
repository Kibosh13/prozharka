# Прожарка

Одностраничный сайт закрытого Telegram-проекта Татьяны Гальцевой: тренировки, питание и растяжка с понятным планом на месяц.

## Структура

- `dist/index.html` — страница лендинга;
- `dist/styles.css` — адаптивная стилизация и анимации;
- `dist/script.js` — навигация, раскрытие контента и эффекты прокрутки;
- `dist/assets/` — оптимизированные фотографии проекта;
- `dist/privacy/`, `dist/consent/`, `dist/offer/` — веб-версии юридических документов;
- `dist/documents/` — исходные юридические документы DOCX;
- `scripts/build_legal_pages.py` — повторная сборка веб-версий документов из DOCX;
- `backend/` — безопасный каркас подписок, webhooks Prodamus и управления доступом в Telegram.

## Локальный просмотр

Откройте `dist/index.html` в браузере или запустите простой статический сервер:

```sh
python3 -m http.server 4173 --directory dist
```

## Публикация

- исходники находятся в ветке `main`;
- статическая демонстрация публикуется из ветки `gh-pages`;
- демонстрационная версия закрыта от поисковой индексации через meta robots и `robots.txt`.

Боевые ключи оплаты и Telegram в репозитории не хранятся. Порядок подключения описан в `backend/README.md`.
